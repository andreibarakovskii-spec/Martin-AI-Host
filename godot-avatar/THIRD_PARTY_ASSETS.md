# Third-party assets and license audit

## Martin v2.4 production model
- Base topology, armature, tail rig, and core locomotion actions: **Cat Pilot (Rigged + Animated)** by Tomcat94.
- Source: https://opengameart.org/content/cat-pilot-rigged-animated
- Source file used by CI: https://opengameart.org/sites/default/files/CatPilot.blend
- License: **CC0 / public domain**.
- The original pilot-specific surface details are removed or covered; Martin-specific face volumes, oversized amber eyes, lids, jaw controls, muzzle, hoodie, logo, headphones, microphone, sneakers, materials and runtime polish are generated by repository scripts.
- The source mesh is smoothed/subdivided and recolored as Martin's continuous gray-fur body while retaining its proven deformation rig and articulated tail.
- Additional NPC state aliases (`Listening`, `Talking`, `Dance`) and facial control bones (`Jaw`, `Eye.L`, `Eye.R`, `Lid.L`, `Lid.R`) are added procedurally for the Android/Godot runtime.
- Fur/material detail is procedural in Blender/Godot; no purchased texture pack is embedded.
- The small runtime `MARTIN` text mesh uses Blender's built-in font; the larger stylized `M` is generated from repository curves.
- Runtime engine: Godot Engine (MIT license).
- Authoring/build tool: Blender (GPL; generated model output is not required to be GPL).
- Paid, trial-only, watermarked, non-commercial-only, or attribution-gated assets: **none**.

## Why the CC0 base is used
The character sheet calls for a soft, continuous anthropomorphic cat. The CC0 Cat Pilot mesh provides a single coherent skinned cat body, six-bone articulated tail and tested walk/run/cheer animation set. It is used only as a freely licensed technical base and is substantially re-authored to match Martin's proportions, clothing, face and accessories.

The production target can be rebuilt entirely from free tools and public-domain/permissive assets.
