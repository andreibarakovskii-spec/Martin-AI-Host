# Production Martin model slot

Place the production avatar here as `martin.glb`.

## Hard requirements
- Free for commercial use. Prefer CC0/public domain.
- Rigged model with a `Skeleton3D` after Godot import.
- Facial blend shapes are preferred (`jawOpen`/`mouthOpen`, blink, smile, or Oculus visemes).
- Mobile target: <= 25k triangles preferred, <= 2 x 1K texture atlases, <= 4 materials.
- Do not commit an asset until its source URL and license are recorded in `THIRD_PARTY_ASSETS.md`.

## Selected free base
Primary base candidate: **Cat Pilot (Rigged + Animated)** by Tomcat94, released CC0/public domain on OpenGameArt. It includes the original Blender file, diffuse texture, rig, walking/running/cheering animations, and eye open/close blendshapes.

The existing procedural Martin remains the fallback while the Cat Pilot source is converted/adapted to GLB.
