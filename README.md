# Martin AI Host

Android AI-тамада для домашнего дня рождения Кати, 35 лет.

Концепция: один Android-смартфон + Bluetooth-колонка + голосовой AI-ведущий Martin на базе Grok. Гости взаимодействуют голосом, а при подключении проектора доступны визуальные конкурсы.

## Adult test build
- wake phrase «Мартин»;
- распознавание речи Android;
- ответы Grok;
- озвучка через Android TTS;
- системный вывод звука на Bluetooth-колонку;
- пауза / стоп / следующая игра;
- анимированный персонаж Martin со состояниями listening / thinking / talking / game / toast / DJ;
- профили гостей, факты и запретные темы;
- голосовое начисление баллов после вопроса «Кто ответил?»;
- каталог конкурсов с обязательным объяснением правил и демонстрационным примером;
- адаптивная иконка приложения Martin;
- режим проектора.

Детский модуль пока не входит в тестовый сценарий взрослой версии.

Проект полностью отдельный от LiveLingo. Сам репозиторий LiveLingo не изменяется.
